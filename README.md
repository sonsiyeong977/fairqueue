\# FairQueue



\*\*결제 실패 없는 공식 티켓팅 보증 레이어 — Powered by Solana \& Gemini\*\*



> Google Cloud x Solana AI Agentic Hackathon 2026 제출작



\---



\## 한 줄 소개



FairQueue는 유저를 대신해 빨리 사주는 매크로가 아니라, \*\*플랫폼의 결제 실패·매출 손실·매크로 문제를 동시에 해결하는 공식 결제 보증 레이어\*\*입니다.



유저가 조건을 걸고 결제 금액을 온체인 에스크로에 미리 예치하면, 에이전트는 정상적인 대기열 순서를 그대로 지키며 기다립니다. 순번이 왔을 때 자금은 이미 확보되어 있으므로 카드 오류·시간 초과 같은 결제 실패가 원천적으로 발생하지 않고, 매진이거나 조건이 맞지 않으면 그 즉시 온체인에서 투명하게 환불됩니다.



\---



\## 문제



\- 대기열 순번이 올 때까지 자리 유무를 알 수 없고, 순번이 와도 결제 자체가 실패하는 경우가 잦습니다.

\- 이는 플랫폼 입장에서 "팔 수 있었는데 놓친" 순수 매출 손실입니다.

\- 매크로/암표 대응, 환불 처리 지연에 따른 CS 비용도 큽니다.



\## 해결책



| | 기존 매크로 | FairQueue |

|---|---|---|

| 대기열 처리 | 우회·편법 | 정상 순서 그대로 (1계정 1에이전트) |

| 목적 | 남보다 빨리 선점 | 결제 실패 방지 + 즉시 투명 환불 |

| 플랫폼과의 관계 | 대립적 | 협력적 (매출 손실 방지 인프라) |

\## 왜 Solana + Google Cloud인가



\*\*Solana\*\*

\- 에스크로 생성/해제가 즉시, 저비용이라 소액도 부담 없이 예치 가능

\- 매진 확정 즉시 온체인 자동 환불 (기존 카드망은 정산 주기상 며칠 소요)

\- 전 과정이 온체인에 기록되어 배정 공정성 분쟁 시 검증 가능



\*\*Google Cloud / Gemini\*\*

\- 자연어 조건 파싱: 유저의 요청을 구조화된 조건으로 변환, 애매하면 되물어 명확화

\- 매진 시 대안 판단: 사전 정의된 우선순위 규칙에 따라 실시간으로 대안 수용 여부 판단

\- 부정 탐지 보조(확장): 요청 로그 패턴으로 매크로 의심 행위 탐지

\- Cloud Run/Firestore: 대기열·에스크로 상태 관리 인프라



\---



\## 기술 스택



\- \*\*AI\*\*: Google Gemini

\- \*\*결제/온체인\*\*: Solana (Devnet), Solana Pay / pay.sh

\- \*\*백엔드\*\*: Google Cloud Run, Node.js

\- \*\*DB\*\*: Firestore

\- \*\*지갑/서명\*\*: `@solana/web3.js`



\---



\## 데모 시나리오



1\. 유저가 자연어로 조건 입력 (예: "아이유 콘서트 R석, 20만원 이하, 2연석")

2\. Gemini가 조건을 구조화 → 에이전트가 대기열 진입

3\. 순번 대기 중 Solana 데브넷에 에스크로 생성 (Explorer로 실시간 확인 가능)

4\. 매진 발생 시 Gemini가 대안 판단 → 조건 충족 시 자동 결제, 불충족 시 즉시 자동 환불
